# 音频预览设计方案（沉浸歌词 · 固定单态）

> 关联原型：`design/audio-preview-redesign.html`（单窗口，含浅色/深色双主题）
> 预览图：`design/preview-light.png`、`design/preview-dark.png`
> **颜色与字号基准：`design/fluent-baseline.md`**（本稿所有色值、字号以该文件为准）
> 目标文件：`src/views/preview/audio.vue`、`src/locales/{zh-CN,en-US}.ts`、`src-tauri/src/preview/window.rs`

## 1. 背景与目标

旧版音频预览在 560×200 的固定窗口内，把封面、文件名、专辑域名、歌词、进度条全部塞进一屏：

- 封面 160px 占宽 28.6%，右侧仅约 360px 承载 5 行文本，歌词实际可用高度不足 3 行；
- 文件名（16px）、专辑域名（13px）、歌词（13px）字号层级过近，被读成同一段落；
- 歌词高亮使用整行浅蓝底色，行宽不齐形成锯齿色块；
- 播放按钮仅在 hover 封面时出现，静止态不可发现；
- 缺少音量、倍速、缓冲进度等基础控制。

结论：**在 200px 高度内无法同时容纳封面、元信息、多行歌词与完整控制**。曾有一版「紧凑态 / 展开态」双形态，最终决定**直接采用沉浸歌词单态**，窗口固定 560×360，不再提供折叠。

## 2. 形态结论

| 形态 | 尺寸 | 定位 |
| --- | --- | --- |
| 沉浸歌词（唯一） | 560×360 | 封面退为模糊背景与 56px 缩略图，5 行歌词 + 完整传输簇 |

固定单态的好处：

- 不存在窗口运行时变形，避免 Windows 上逐帧 `setSize` 的掉帧与重绘撕裂；
- 不需要 `expanded` 状态机、展开/收起按钮与状态持久化；
- 窗口尺寸由创建时决定，前端无需再次调整窗口，也不依赖窗口 ACL 的 `set-size` 权限。

```

│  ▓▓ 模糊封面背景 + 0.76 主题蒙版 ▓▓      [×] │
│  ┌──┐ 文爱  MP3  320k                         │
│  │56│ CG、贺敬轩 · 文爱                        │
│  └──┘                                        │
│            作词：CG                           │
│            作曲：Luck Christopher             │

│            痴情一场我却不后悔                 │
│            我的心里只有一个你                 │
│  01:12 ──●────── -02:08                      │
│        ⏪  ▶  ⏩   🔊   1×                  │
└──────────────────────────────────────────────┘
```

| 区块 | 规格 |
| --- | --- |
| 窗口 | 560×360 物理像素，与图片/视频预览共用同一套 DPI 换算，高缩放系统下逻辑尺寸随之收缩（150% 为 373×240） |
| 背景 | 封面 `background-size: cover`，`inset: -14%`，`blur(34px) saturate(1.35)`，opacity 0.72 |
| 蒙版 | 主题色 `--color-bg`，opacity 0.76，保证文字对比度不依赖封面色 |
| 容器 | `padding: 20px 24px 16px`，`row-gap: 8px`，四行网格 `auto / 1fr / auto / auto`（下表的 px 均为 560×360 下的设计值） |
| 顶部行 | 56×56 缩略封面 + 标题 16px/600 + 规格胶囊 + 副标题 12px，右侧预留 40px 避开窗口按钮 |
| 歌词 | 可视区 150px，5 行可见，行高 30，当前行 20px/600 主色，上下 9% 遮罩渐隐 |
| 进度条 | 轨道 4px，hover 增至 6px，thumb 10px，时间 12px `tabular-nums` |
| 传输簇 | 居中，后退 10s / 播放 46px / 前进 10s / 音量 / 倍速，间距 14 |

### 3.1 DPI 缩放与自适应

窗口物理尺寸恒为 560×360，因此系统缩放比越高，WebView 拿到的逻辑视口越小：

| 系统缩放 | 逻辑视口 | 歌词字号 / 当前行 | 可见歌词行 |
| --- | --- | --- | --- |
| 100% | 560×360 | 14 / 20 | 5 |
| 125% | 448×288 | 12 / 16 | 4 |
| 150% | 373×240 | 12 / 16 | 4 |
| 200% | 280×180 | 12 / 16 | 3 |

做法：在 `.audio-wrapper` 上定义 `--u: 0.2778vh`（1 设计像素 = 1/360 视口高），所有几何尺寸写成 `calc(N * var(--u))`，最高不超过设计值（`min(56px, calc(56 * var(--u)))`）。字号不跟着等比缩，改为 `clamp()` 保下限（歌词 12px、标题 14px、时间 12px），否则 200% 下正文会掉到 9px 不可读。

品牌色按 `design/fluent-baseline.md` §2.1 拆分：文字与图标用 `--color-brand-fg`（浅色 `#0F6CBD` / 深色 `#479EF5`），实心底用 `--color-accent`（`#0078D4`）。组件内 `--audio-accent` / `--audio-accent-hi` 直接引用这两支，不再自持色值。

## 4. 交互

| 区域 | 行为 |
| --- | --- |
| 标题、副标题、胶囊、留白 | 拖动移动窗口（`data-tauri-drag-region="deep"`） |
| 封面 | 拖动移动窗口（阈值 4px，避免误触） |
| 歌词行 | 单击跳转到该句；拖动移动窗口 |
| 播放 / 后退 / 前进 / 音量 / 倍速 | 正常点击，不触发拖拽 |
| 进度条、音量滑块 | 拖动取值，不触发拖拽 |
| 右上角 | 关闭按钮（hover 显现） |

键盘：`Space` 播放暂停、`← / →` 前后 10 秒、`↑ / ↓` 音量 ±0.05、`Esc` 关闭。

窗口拖动注意点：Tauri 2.12 的 `drag.js` 中，裸属性 `data-tauri-drag-region` 只对「直接点在该元素本身」生效，子元素点击会阻断向上查找，因此必须用 `="deep"`；封面与歌词行另有点击语义，标为 `="false"` 并自行按位移阈值调用 `startDragging()`。

## 5. 音量调节（替代单曲循环）

单文件预览场景不存在播放列表，循环语义价值低；音量是每次预览都可能调整的高频控制。

| 行为 | 反馈 |
| --- | --- |
| 单击音量图标 | 静音 / 取消静音（记忆静音前音量） |
| 悬停音量图标 | 上方浮出竖向滑块面板（宽 40、滑块高 80） |
| 拖动滑块 | 实时写入 `audio.volume`，图标随档位切换 |
| 键盘 ↑ / ↓ | 音量 ±0.05，与滑块双向同步 |

图标四档映射：

| 音量 | 图标 |
| --- | --- |
| = 0 | `SpeakerMute16Regular` |
| < 0.34 | `Speaker016Regular` |
| < 0.67 | `Speaker116Regular` |
| ≥ 0.67 | `Speaker216Regular` |

浮层定位：`bottom: 30px`，水平居中；仅在 hover 时可见，浮层会短暂压住最后一行歌词与进度条中段，可接受。

## 7. 顺带修复的既有缺陷

| 缺陷 | 影响 | 处理 |
| --- | --- | --- |
| `parse_lrc` 失败未捕获 | 无 `.lrc` 文件时 `onMounted` 中断，`audio.src` 未赋值，音频无法播放 | `try/catch` 降级为空歌词，不阻塞音频加载 |
| `syncLyrics` 循环内 `break` 赋值 | 超过最后一行歌词后索引停留在错误值 | 改为从尾部向前查找首个已到达行 |
| 以 `timestamp` 作匹配键 | 重复时间戳歌词同时高亮 | 改用行索引比较 |
| `document.querySelector('.lrc-active')` + `scrollIntoView` | 全局选择器、连带滚动外层容器 | 容器内 `scrollTop` 计算居中 |
| rAF 自递归无统一取消 | 暂停后可能残留循环 | 统一 `rafId` 引用 + `cancelAnimationFrame` |
| 事件监听未解绑 | 组件卸载后回调仍触发 | `AbortController` 统一解绑 |
| `IAudioInfo` 字段声明为非空 | 后端实际返回 `Option<T>`，类型与运行时不符 | 全部改为可空，配套空值处理 |

## 9. 风险与取舍

- **背景模糊性能**：`filter: blur(34px)` 作用在内联背景层，静态且只渲染一层，对滚动帧率影响可忽略。
- **歌词长行**：560 宽度下 20px 字号的超长歌词会省略，不做自动缩放（缩放会导致行高跳动，破坏居中节奏）。
- **音量浮层遮挡**：360 高度下竖向浮层必然压住歌词末行与进度条中段，仅在 hover 时出现。
- **窗口可缩放**：用户手动拉小窗口时歌词区会被压缩（最小 300×200），布局为弹性网格，不保证美观。
- **高 DPI 下窗口偏小**：物理尺寸恒为 560×360，150% 系统缩放下相当于其它窗口的 2/3，属于有意取舍——换来与图片/视频预览一致的换算规则。
- **胶囊缺采样率**：后端 `MusicInfo` 只提供标题 / 艺术家 / 专辑 / 时长 / 码率 / 封面，故只显示扩展名与码率，不臆造 44.1K。
