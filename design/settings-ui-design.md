# 设置页 Fluent 风格重设计方案

> 范围：`src/views/settings.vue`、`src/components/setting-item.vue` 及其所在的设置窗口
> 关联原型：`design/settings-redesign.html`（浅色/深色，`?theme=dark#theme` 深链）
> 视觉基准：`design/preview-ui-design.md`、`design/audio-preview-design.md`（同一套 Fluent 语言）
> **颜色与字号基准：`design/fluent-baseline.md`**（本稿所有色值、字号以该文件为准）
> 版本基线：v1.0.0
> 实现状态：已按本方案落地（`src/views/settings.vue`）。标题行采用「保留系统标题栏」形态，
> P2 提案（缓存体积显示、检查更新入口）未实现，验收时跳过对应条目。
> 搜索框 / 扩展名输入框 / 日志级别下拉已改用 Element Plus 的 `el-input` / `el-select`，
> 通过 `--el-*` 变量映射重皮，§4.4 的视觉规格不变（见 §4.4.1）。
>
> **本文是设计方案，不含实现代码；实现以 `src/views/settings.vue` 为准。**

## 1. 背景与目标

预览窗口已在 v1.0.0 统一为「标题行 44px → 命令栏 40px → 内容区」的 Fluent 外壳：单一底色、透明标题行、控件常态无底色、元信息贴着标题、不设状态栏。设置窗口仍是上一代的形态——顶部一条横向 `el-anchor` 胶囊导航，下面 7 张带边框、带投影的卡片纵向堆叠，控件全部是 Element Plus 默认外观。

目标不是给旧页面换色，而是让设置窗口与预览窗口看起来属于同一个应用：

1. 建立**左侧导航 + 右侧分组内容**的信息架构，原有 7 个分组不再挤在同一条滚动流里；
2. 用 Fluent 的**设置卡片 / 设置行**取代「卡片套卡片、虚线框、彩色块」；
3. 控件换成 Fluent 语义（ToggleSwitch、Segmented、ComboBox、Pill、SubtleButton、InfoBar），并统一右对齐；
4. 复用既有 `--color-*` / `--font-*` / `--radius-*` / `--space-*` 变量，深色模式不额外调色；
5. 把主题切换从「预览窗口标题栏的一次性按钮」收进**常规分组**，做成三态设置项，与快捷按钮共用同一状态。

## 2. 现状诊断

| 区域 | 现状 | 问题 |
| --- | --- | --- |
| 导航 | `el-anchor` 横向 7 个链接，sticky 在内容之上，带 `--color-surface` 底 + 1px 边框 | 与「不做条带切割」冲突；窄窗口横向溢出，7 个入口没有层级、无法搜索 |
| 分组 | 7 张 `.setting-card`，各带 1px 边框、`radius-lg`、轻投影，头部还有一条 `border-bottom` | 每张卡片都用同一权重，视觉上变成 7 个互不相干的模块；卡片内再套 `.ext-sub` 虚线框与 `.cache-item` 实线框，形成三层嵌套边框 |
| 标题 | 图标 + `font-lg` 标题 + 描述，图标为 `--font-2xl` 纯色 | 图标过大、与标题抢注意力；缺少「页面标题」这一层，导航项和卡片标题是同一级字号 |
| 控件 | `el-radio-button`、`el-switch`、`el-input` + `el-button`、`el-tag`、`el-alert`、`type="danger" plain` 按钮 | 全是 Web 表单默认观感；彩色 `.format-card-code` 胶囊（蓝底白字）与危险色描边按钮，在一个以透明/悬浮为语言的界面里过于抢眼 |
| 状态 | `el-alert` 整块彩色底 + 边框 | 与 InfoBar 的轻量语义不符；「检测中/可用/不可用」三态没有统一的图标与留白规格 |
| 空态 | 一行 `font-sm` 灰色文字 | 与预览页的居中状态卡片不一致，且没有说明「输入后会怎样」 |

两处结构性问题：

1. **没有真正的导航**：锚点只是把长页面「跳」到某处，用户仍要在一屏里面对 7 组内容；分组之间缺少空间隔离，滚动位置与当前分组没有稳定对应。
2. **视觉噪音来自层级，而不是颜色**：卡片边框、头部下边框、虚线子框、缓存行边框、彩色徽章同时存在。Fluent 的做法是只保留「卡片 + 行间发丝线」两级。

## 3. 设计原则

沿用 `preview-ui-design.md` §3 的六条硬约束（不做条带切割、控件悬浮、标题即第一层、取消状态栏、一种形态一套层级、只用既有变量），并补充设置页特有的四条：

1. **卡片是唯一的分层手段**。卡片内部只用 1px `--color-divider` 发丝线分行；禁止卡片内再嵌套带边框的卡片、禁止虚线框。
2. **一个分组一屏**。左导航切换分组，右侧一次只呈现一个分组；滚动容器唯一，即右侧内容区。
3. **控件右对齐，文字左对齐**。设置行统一 `min-height: 52px`，左侧标题 14px/600 + 描述 12px 次要色，右侧控件贴右缘；命中区 ≥ 32px。
4. **危险操作降级**。清理缓存是常规维护，不是警告事件：用「subtle 按钮 + 危险色文字」，不用红色描边实心按钮；执行后以轻量 toast 反馈。

## 4. 统一框架

### 4.1 三层结构

```
┌──────────────────────────────────────────────────────────────┐
│ 设置                                                [─] [✕]  │  标题行 44 · 透明
├──────────────────┬───────────────────────────────────────────┤
│ 🔍 查找设置       │  语言                                     │  页面标题 24/600
│                  │  界面显示语言与应用行为                    │  副标题 12 次要色
│ ▌ 常规    语言    │  ┌───────────────────────────────────────┐ │
│   主题            │  │ ◉ 界面语言          [简体中文│English] │ │  设置卡片
│   支持的格式      │  │ ───────────────────────────────────── │ │  行间发丝线
│   代码格式        │  │ ◉ 跟随系统          [  Toggle  ]      │ │  ≥52px
│   视频            │  └───────────────────────────────────────┘ │
│   缓存            │                                           │
│   日志            │                      ← 唯一滚动容器 →      │
│   关于            │                                           │
│  QuickLook v1.0.0 │                                           │
└──────────────────┴───────────────────────────────────────────┘
     导航 240px                     内容 1fr
```

| 区块 | 尺寸 | 背景 | 说明 |
| --- | --- | --- | --- |
| 标题行 | 44px，与 `--layout-header-h` 一致 | **透明** | **只放标题「设置」16px/600**，不放软件名与版本胶囊（与「关于」分组重复，且会把标题行读成文件预览的元信息行）；右侧窗口按钮 34×30、hover 才浮底；关闭 hover 转红 |
| 左导航 | 240px，`flex: none` | `--color-surface` 60% + 12px blur（亚克力） | 与内容区的分界只用 1px `--color-divider`，不加投影 |
| 内容 | 1fr，`max-width: 720px` 内容列 | `--color-bg` | 唯一滚动容器；滚动条 8px、细样式，与预览窗口一致 |

> 标题行是**设计目标**，实现上需要把设置窗口也改成 `decorations(false)` 并注册拖拽区；若本期保留系统标题栏，则直接省略这一行，左导航与内容区各占满窗口高度，其余规格不变。两种形态都在原型里可对照。

### 4.2 左侧导航

| 项 | 规格 |
| --- | --- |
| 搜索框 | 高 32px，`--color-chip-bg` 填充、无描边、`--radius-md`，左 14px 放大镜图标；输入即时过滤下方导航项（实现为 `el-input` + `#prefix` 图标） |
| 导航项 | 高 36px，图标 16px + 文字 14px，左右内边距 12px，间距 2px；常态 `--color-text-secondary` |
| 激活态 | `--color-selected-bg` 底 + 文字 `--color-text-primary` + 600 字重；**左侧 3px × 18px 圆角指示条**用 `--color-brand-fg`（贴卡片左缘，不占文字位置） |
| hover | `--elevation-hover` 底 + 文字转主色；不使用边框 |
| 分组标签 | 「常规」「内容」「维护」「关于」四组，10px 大写字距 0.04em、`--color-text-disabled`，组间 16px 留白；不画分隔线 |
| 底部 | 「QuickLook v1.0.0」12px 次要色，贴导航底；这是版本信息的唯一常驻位置，标题行不重复 |

导航项共 **8 项**，顺序与 i18n 键对应：`语言 / 主题 / 支持的格式 / 代码格式 / 视频 / 缓存 / 日志 / 关于`。「语言」「主题」归入「常规」，不再单列顶部锚点。舞台左下角的浅/深分段只是**原型演示控件**，窗口内真正切换主题的是「常规 · 主题」页（见 §5.2），两者在原型里联动同一个状态。

### 4.3 设置卡片与设置行

```
卡片  background: --color-surface    border: 1px --color-border    radius: --radius-lg
      padding: 4px 16px             shadow: none
行    min-height: 52px  display:flex  align-items:center  gap:16px
      + 行间 1px --color-divider（最后一行不加）
标题  14px/600 --color-text-primary      描述 12px/16px --color-text-secondary
控件  margin-left:auto  flex:none       命中区 ≥32px
```

- 卡片**没有头部下边框**，也没有图标标题行；分组的语义由页面标题承担。
- 卡片之间 16px，页面标题到首张卡片 24px。
- 多行同构内容（缓存三行、格式列表）走同一套行规格，不再各自画框。
- 副标题/说明放在页面标题下方（12px、`--color-text-secondary`），卡片里只留逐行的短描述。

### 4.4 控件规格

| 控件 | 规格 | 用在哪 |
| --- | --- | --- |
| ToggleSwitch | 40×20，轨道 `--color-chip-bg` / 开启 `--color-accent`，滑块 12px 圆；Fluent 无文字标签 | 使用 ffmpeg 解析 |
| Segmented | 高 32px，`--color-chip-bg` 底，选中片 `--color-surface` + 1px 细边 + 文字主色 | 语言（2 项）、主题（3 项） |
| ComboBox（`el-select`） | 高 32px，1px `--color-border` + 透明底，右侧箭头 | 日志级别（6 项，_segmented 太宽_） |
| TextBox（`el-input`）+ 图标按钮 | 输入框**定宽 200px**、高 32px；右侧仅一个 32×32 的 `+` 图标按钮 | 自定义扩展名 |
| Pill / Chip | 高 22px，`--color-chip-bg` 底、无描边、右侧 12px ×；hover 才显 `--elevation-hover` | 扩展名标签、格式扩展名 |
| SubtleButton | 高 32px，无边框无底色，文字 14px；hover `--elevation-hover` | 清理缓存、打开链接 |
| AccentButton | `--btn-primary-*`，高 32px，圆角 `--radius-sm` | 仅保留一个主操作（如「检查更新」） |
| InfoBar | `--color-accent-soft` 底、左侧 16px `--color-brand-fg` 状态图标、标题 14px/600 + 描述 12px（均为中性文字色）、无边框、无关闭按钮 | ffmpeg 检测三态 |
| 空态 | 卡片内一行 12px 次要色文字 + 引导语，不加边框、不加居中大图标 | 无自定义扩展名时 |

三档 Segmented（跟随系统 / 浅色 / 深色）总宽约 190px，720px 内容列容纳得下，不必降级为 ComboBox；六档以上才用下拉。

> 输入框定宽沿用预览工具栏的结论（见 `preview-ui-design.md` §4.2.1）：只给 `max-width` 时输入后出现的清空/提交元素会把盒子撑长，命令栏与设置行都会抖。

### 4.4.1 表单控件的组件实现（实现层补充）

视觉规格仍以 §4.4 为准，底层控件改用项目已按需引入的 Element Plus，避免自己维护一套原生输入框 / 下拉的焦点态、禁用态与可访问性：

| 位置 | 组件 | 备注 |
| --- | --- | --- |
| 左导航搜索 | `el-input` + `#prefix` 放大镜 | 无描边填充，聚焦时才用 `--color-brand-fg` 描边 |
| 代码格式 / 视频扩展名 | `el-input` | 定宽 200px；`@keyup.enter` 透传到内部原生 input 后添加 |
| 日志级别 | `el-select` + `el-option` | 6 档；`@change` 写回 store 与后端日志级别 |

换皮规则（不新增依赖、不改视觉规格）：

- 在 `.st-search` / `.st-textbox` / `.st-combo` 上把 `--el-input-*`、`--el-fill-color-blank`、`--el-border-color*`、`--el-color-primary`、`--el-disabled-*` 映射到既有 `--color-*`；scoped 选择器带 `data-v` 属性，优先级高于组件自带样式，深/浅色随 `html.dark` 自动切换。
- `el-select` 的下拉由 Teleport 挂到 `body`，拿不到 scoped 作用域，用 `popper-class="st-select-popper"` 配一段非 scoped 样式单独映射浮层变量；箭头、圆角、hover / 选中色仍来自同一套主题变量。
- 全局 ↑/↓ 切换分组时要跳过聚焦在 `.el-input` / `.el-select` / `[role="combobox"]` 的情况，否则会与下拉的选项导航抢按键。
- `design/settings-redesign.html` 是**不依赖组件库的静态原型**，仍用原生 `input` / `select` 做视觉等价演示；以本节为组件实现依据。

## 5. 逐分组规格

### 5.1 常规 · 语言

```
页面标题   语言
副标题     选择界面显示语言，切换后立即生效并同步到所有窗口
卡片
  行 1     界面语言        描述：托盘菜单、系统对话框与窗口标题会一起切换
                          [ 简体中文 │ English ]（Segmented，当前项高亮）
  行 2     切换状态        描述：切换期间短暂无响应属正常现象
                          右侧为 12px 次要色文字「已同步」（只在切换完成后出现）
```

- 不新增「跟随系统」项：当前实现只有 `zh-CN` / `en-US` 两档，设计不凭空扩选项。
- 切换中禁用 Segmented 并显示 12px 内联进度点，不用整屏 loading。

### 5.2 常规 · 主题

```
页面标题   主题
副标题     选择应用外观，切换后立即同步到所有预览窗口
卡片
  行 1     应用主题        描述：跟随系统时会随系统深浅色设置自动切换
                          [ 跟随系统 │ 浅色 │ 深色 ]（Segmented 三档，默认「跟随系统」）
  行 2     当前生效        描述：预览窗口标题栏的太阳 / 月亮按钮可快速切换明暗
                          右侧为 12px 次要色只读文字「浅色（跟随系统）」/「深色」
```

- 三档直接对应 `useTheme()` 里 `useColorMode` 的 `auto / light / dark`，**不新增数据模型**：现有 `store`（localStorage `vueuse-color-scheme`）已能表达三态，只是 `header.vue` 的 `toggle()` 只暴露了明 / 暗二态。
- 预览窗口标题栏的太阳 / 月亮按钮保留为**快捷切换**：点它等价于直接选「浅色」或「深色」（脱离 `auto`），结果立刻反映到本页选中态与「当前生效」；想回到自动只能在本页重选「跟随系统」。不给快捷按钮加长按 / 右键菜单。
- 「当前生效」是只读状态而非可点开关；`auto` 时显示系统实际值并标注「（跟随系统）」，避免被误读成设置没生效。
- 切换即时生效、无保存按钮、无重启提示；不弹 toast——整窗配色变化本身就是反馈。
- 影响范围：所有窗口共用 `html.dark`，代码 / Markdown 高亮、PDF 画布、EPUB 纸张底色一并跟随。EPUB 的 `watch(isDark)` 会把纸张重置为浅 / 深色，属既有行为，本设计不额外干预。
- 需补中英文案：`settings.nav.theme` 与 `settings.theme.*`（标题、描述、三档标签、当前生效）；不新增颜色变量。

### 5.3 内容 · 支持的格式

```
页面标题   支持的格式
副标题     QuickLook 已识别的文件类型与对应扩展名
卡片       10 行列表，每行：格式名 14px/600 + 右侧扩展名 Pill 组
           行间发丝线；扩展名多时换行，行高随内容增高（min 52px）
```

- 取消现在的 10 张小卡片与蓝底白字 `CODE` 徽章：10 个等权重小卡片在 240px 列宽下会折成多列，且与「一张卡片 + 行」的层级冲突。
- 扩展名 Pill 用 `--color-chip-bg`，不用 `el-tag` 的彩色描边。
- 副标题右侧放 12px 次要色统计「共 10 类 · N 个扩展名」（N 按 `config.json` 实时统计），裸文本不加胶囊；原型里固定写「共 10 类」示意。

### 5.4 内容 · 代码格式

```
页面标题   自定义代码格式
副标题     添加额外扩展名（如 rb、lua），添加后即可用代码预览打开
卡片
  行 1     已添加的扩展名   右侧 Pill 组（可点 × 移除）；无内容时显示空态引导语
  行 2     添加扩展名       右侧 [ 输入框 200px ] [ + ]（图标按钮）
```

- 输入即时校验：去掉前缀 `.`、转小写、去重；重复时输入框下沿用 12px `--color-danger-fg` 文字提示，不弹 toast。
- 「添加」不再使用主色实心按钮，行内图标按钮即可（该操作在当前分组里每天用不了几次）。

### 5.5 内容 · 视频

```
页面标题   视频
副标题     启用 ffmpeg 后，兼容视频直接播放，不兼容时自动转码
卡片
  行 1     使用 ffmpeg 解析视频   描述：兼容格式直接播放，不兼容时自动转码    [Toggle]
InfoBar    （仅开关打开时）检测中 / 可用 / 不可用，图标随态切换
卡片
  行 2     自定义视频扩展名       描述：需先启用 ffmpeg 解析；关闭时整行置灰
```

## 6. 状态与反馈

| 场景 | 形态 |
| --- | --- |
| 设置变更 | 即时生效，无保存条；右上角 12px 次要色「已保存」出现 2s 后淡出 |
| 切换语言 | Segmented 禁用 + 内联进度点；完成后「已同步」 |
| 切换主题 | **不弹「已保存」/ toast**：整窗配色变化本身就是反馈；选中态与「当前生效」即时更新，标题栏快捷切换也会同步回写 |
| ffmpeg 检测 | InfoBar 三态（info / success / error 图标），位置固定不撑高页面 |
| 重复扩展名 | 输入框下方 12px `--color-danger-fg` 文字，输入清空后消失 |
| 清理缓存 | 按钮内联 loading → 同位置「已清理 N 项」→ 淡出；失败时改 InfoBar |
| 空态 | 行内 12px 次要色引导语，不使用大图标卡片 |

所有反馈都不使用整屏遮罩、不使用 `ElMessage` 式的悬浮弹层——设置页已有固定的信息位置，弹层会破坏「一个分组一屏」的稳定感。

## 7. 响应式

| 断点 | 处理 |
| --- | --- |
| ≥ 1000px | 240px 导航 + 720px 内容列，左右各留 32px |
| 760–999px | 导航收窄到 200px，内容列自适应，卡片内边距降到 12px |
| ≤ 759px | 导航折叠为顶部 44px 横向分段条（可横向滚动），内容占满宽度；页面标题降到 20px；设置行改为上下两行（文字在上、控件在下，仍右对齐） |
| ≤ 520px | 扩展名输入框宽度改为 `100%`，`+` 按钮换行；Pill 组允许折行 |

不引入抽屉式导航：设置页是短时停留的窗口，多一次点击比横向滚动更麻烦。主题的三档 Segmented（约 190px）在 520px 断点下仍保持单行，不折成竖排；只有扩展名输入框需要随断点变宽。

| 级别 | 内容 | 说明 |
| --- | --- | --- |
| P0 | 左导航 + 分组切换、设置卡片/行规格、控件换 Fluent 语义 | 决定「是不是同一个应用」 |
| P0 | 去掉嵌套边框、彩色徽章、危险色描边按钮 | 视觉噪音主要来源 |
| P1 | 搜索设置项、InfoBar 三态、输入框定宽与内联校验 | 交互完整度 |

## 9. 风险与取舍

- **左导航切换 vs 单页长滚动**：Fluent 设置页用左侧导航，代价是每次切换都要重新定位滚动位置；8 个分组内容都不长，切换比滚动更快，且「当前分组」始终明确。原型按切换实现。
- **亚克力底**：`backdrop-filter` 在 WebView2 上成本可控，但窗口无透明内容时几乎看不出效果；若实测掉帧，直接退化为纯 `--color-surface`，视觉层级不受影响。
- **系统标题栏**：当前设置窗口由 `WebviewWindowBuilder` 动态创建、保留系统装饰。改成自绘 44px 标题行需要 `decorations(false)` 与拖拽区，属跨端改动；设计里把它列为可选项，不阻塞 P0。
- **只新增「主题」一个设置项**：它复用 `useColorMode` 已有的 `auto / light / dark` 三态与 localStorage 键，不新增 `config.data` 字段、不改后端命令；除「缓存体积」「检查更新」两个 P2 提案外，其余都是重排既有功能。
- **快捷切换与设置项的语义**：`header.vue` 的 `toggle()` 只会写入明 / 暗，一旦点过就脱离「跟随系统」。设计上不隐藏这个按钮、也不把它改成三态菜单，而是在设置页用「当前生效」把实际来源说清楚，并让本页成为唯一能恢复「跟随系统」的入口。
- **i18n**：文案沿用现有 `settings.*` 键；新增文案（搜索占位、已保存、分组标签、`settings.nav.theme` 与 `settings.theme.*`）需补中英双份，设计稿只给中文示意。
